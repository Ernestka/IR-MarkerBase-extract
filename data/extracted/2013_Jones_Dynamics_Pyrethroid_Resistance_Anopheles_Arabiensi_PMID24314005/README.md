# Decisions and Extraction Summary

- **Study Overview**: Field monitoring of insecticide resistance and underlying mechanisms in Zanzibar (Unguja and Pemba islands), Tanzania, covering larval collections from 2011 to 2013.
- **Surveys**: Target-site mutation screening data were reported pooled across the three collection years (2011–2013) separately for the two main islands: Unguja (N = 120) and Pemba (N = 251). Surveys are defined at the island level (`admin1`). The populations were Anopheles gambiae s.l. (predominantly An. arabiensis, with minor fractions of An. gambiae s.s. and An. merus as shown in Table 1).
- **Target-site Markers**: Screened for Vgsc 1014F, Vgsc 1014S, and Ace-1 G119S (ace-1R) by TaqMan assays. None of the resistance alleles were observed in either island population (RR = 0, RS = 0, SS = 120 on Unguja; RR = 0, RS = 0, SS = 251 on Pemba). Sequencing of sodium channel exon 20 also revealed no non-synonymous mutations.
- **Bioassays**: Diagnostic dose bioassays with lambda-cyhalothrin, permethrin, and DDT were reported graphically in bar charts (Figure 3) and in Additional file 2, without individual sample sizes printed in the main text. Only bendiocarb (0.1%) bioassays had explicit sample sizes and mortalities reported in the main text on page 7 (Unguja N = 57, 100% mortality; Pemba N = 192, 100% mortality); these were extracted with `dead_alive_printed: false`.
- **Genotype-Phenotype**: Target markers were completely absent in the tested samples, so no genotype-phenotype associations were reported.
